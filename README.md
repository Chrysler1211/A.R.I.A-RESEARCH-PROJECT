# 📖 Introduction

**A.R.I.A. (Advanced Litter Gathering for Parents through Innovative Support)** is a **semi-automatic litter gathering robot** developed as a Senior High School research project.

The robot was created to assist parents by making litter collection easier, safer, and more efficient. Through Bluetooth communication and an Arduino-based control system, users can remotely operate the robot using a mobile application while controlling its movement and robotic claw.

Rather than replacing human effort, **A.R.I.A. serves as an intelligent robotic assistant**, reducing physical effort while promoting environmental cleanliness through affordable robotics technology.

This project combines robotics, embedded systems, Arduino programming, Bluetooth communication, and mobile application development into one practical solution.

# 🌍 Project Overview

A.R.I.A. is a **semi-automatic robotic litter gathering system** that combines embedded hardware and software technologies to simplify waste collection.

Using a Bluetooth-connected Android application, users can remotely drive the robot, operate its robotic claw, and collect litter without direct physical interaction.

This project demonstrates the practical application of robotics, embedded systems, and wireless communication while encouraging innovation and environmental responsibility.

---

# 🎯 Objectives

- Design and develop a semi-automatic litter gathering robot.
- Assist parents in collecting litter more efficiently.
- Integrate Arduino-based embedded systems.
- Implement Bluetooth communication for wireless robot control.
- Develop an intuitive Android mobile application.
- Promote environmental cleanliness using robotics technology.

# ⚙ Installation Guide

## Arduino Setup

1. Install the Arduino IDE.
2. Connect the Arduino Uno.
3. Upload the source code.
4. Connect the HC-05 Bluetooth module.
5. Power on the robot.

## Mobile Application Setup

1. Install the Android application.
2. Enable Bluetooth.
3. Pair with the HC-05 module.
4. Connect to the robot.
5. Begin operating A.R.I.A.

---

# ▶ Usage

1. Turn on A.R.I.A.
2. Open the Android application.
3. Connect via Bluetooth.
4. Drive the robot.
5. Position the robotic claw.
6. Collect litter.
7. Continue operation until the area is clean.
